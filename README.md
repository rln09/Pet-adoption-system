# Pet Adoption System

A command-line based pet shelter management system built with Object-Oriented Programming principles in Python.

## Features

- Add new pets (dogs and cats) to the shelter
- List all available pets
- Search for pets by type, breed, or age
- Adopt pets (mark them as adopted)
- Display detailed information about specific pets
- Save and load shelter data from CSV files
